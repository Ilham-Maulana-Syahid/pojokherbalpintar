PENJELASAN LENGKAP WEBSITE
POJOK HERBAL PINTAR
================================

Dokumen ini adalah panduan presentasi dan live demo website Pojok Herbal
Pintar. Website ini merupakan platform edukasi herbal Indonesia yang
menggabungkan katalog herbal, resep herbal, peta herbal interaktif, dan
konsultasi Herbal AI.

1. IDENTITAS DAN TUJUAN
-----------------------

Tujuan website:
- Memberikan edukasi tentang tanaman herbal Indonesia.
- Menampilkan manfaat, kandungan, bagian tanaman, cara pembuatan, keamanan,
  dosis, dan sumber foto.
- Membantu pengguna menemukan herbal berdasarkan provinsi.
- Menyediakan asisten AI untuk pertanyaan seputar herbal dan jamu.
- Mendukung edukasi kesehatan masyarakat di Posyandu dan Puskesmas.

Sasaran pengguna:
- Masyarakat umum.
- Kader Posyandu dan Puskesmas.
- Pelajar dan mahasiswa.
- Pengguna yang ingin mengenal jamu dan tanaman obat Indonesia.

Catatan: website ini bersifat edukatif dan bukan pengganti diagnosis,
resep, atau konsultasi langsung dengan dokter dan apoteker.

2. TEKNOLOGI
------------

- Next.js 14 dengan App Router.
- React 18 dan TypeScript.
- Tailwind CSS.
- Framer Motion untuk animasi.
- Lucide React untuk ikon.
- Google Gemini melalui @google/generative-ai.
- SVG untuk peta Indonesia.
- JSON sebagai data utama herbal.
- Service worker untuk cache dan pengalaman offline dasar.

Perintah utama:
- npm run dev       Menjalankan mode pengembangan.
- npm run lint      Memeriksa aturan linting.
- npx tsc --noEmit  Memeriksa TypeScript.
- npm run build     Membuat build production.
- npm start         Menjalankan build production.

4. KATALOG HERBAL (/katalog)
----------------------------

Katalog digunakan untuk mencari dan membaca detail herbal.

Fitur:
- Pencarian nama herbal, nama latin, manfaat, atau bagian tanaman.
- Kartu foto herbal.
- Nama dan nama latin.
- Manfaat utama.
- Modal detail.
- Sumber foto.
- Disclaimer medis.

Detail yang tersedia:
- Nama herbal dan nama latin.
- Manfaat.
- Bagian tanaman yang digunakan.
- Kandungan.
- Cara pembuatan.
- Dosis dan keamanan.
- Sumber foto.

Aturan manfaat:
- Manfaat hanya ditampilkan di Katalog Herbal.
- Teks yang berisi beberapa manfaat dapat dipisah menjadi beberapa poin jika
  pemisahnya jelas.
- Frasa yang harus tetap satu makna tidak dipisah secara sembarangan.

Indikasi medis:
- Bagian "Indikasi Medis" sudah dihapus dari tampilan katalog karena sumber
  data tidak menyediakan indikasi medis terpisah secara konsisten.
- Website tidak membuat atau mengarang informasi indikasi medis baru.

Alur demo:
1. Buka menu "Katalog Herbal".
2. Cari "Kunyit", "Mengkudu", atau "Pala".
3. Klik kartu herbal.
4. Tunjukkan manfaat dalam poin yang rapi.
5. Tunjukkan bagian tanaman, kandungan, cara pembuatan, dosis, dan sumber foto.
6. Tutup modal dengan tombol X atau area di luar modal.

5. RESEP HERBAL (/resep)
------------------------

Halaman Resep Herbal berfokus pada pengolahan herbal, bukan daftar manfaat.

Yang ditampilkan:
- Foto herbal.
- Nama dan nama latin.
- Jumlah bagian tanaman.
- Bagian tanaman yang digunakan.
- Kandungan.
- Cara membuat.
- Keamanan, dosis, dan interaksi.
- Tombol detail.
- Tombol cetak resep.
- Sumber foto.

Manfaat tidak ditampilkan di halaman resep. Manfaat hanya ada di katalog.

Kandungan:
- Kandungan yang dipisahkan koma dapat menjadi item bernomor.
- Koma pada angka atau nama senyawa, seperti "1,8-cineole", tidak dipotong.
- Frasa dengan kata "atau" dipertahankan sebagai satu item.

Cara pembuatan:
- Ditampilkan sebagai tahapan pengolahan.
- Instruksi konsumsi seperti "minum 2x sehari", "minum sebelum makan",
  atau "1 gelas per hari" tidak termasuk cara pembuatan.
- Informasi konsumsi tetap berada pada bagian dosis.

Cetak resep:
1. Klik ikon printer pada kartu atau modal.
2. Browser membuka halaman cetak.
3. Pilih printer atau simpan sebagai PDF.

Alur demo:
1. Buka "Resep Herbal".
2. Cari "Kunyit" atau "Jahe".
3. Tunjukkan kandungan dalam nomor terpisah.
4. Tunjukkan cara pembuatan sebagai langkah pengolahan.
5. Tunjukkan bahwa manfaat tidak tampil di resep.
6. Klik printer untuk mencoba mencetak.

7. HERBAL AI (/ai)
------------------

Herbal AI adalah fitur konsultasi berbasis Gemini LLM.

Fungsi:
- Menjawab pertanyaan tentang herbal, jamu, wedang, dan tanaman obat.
- Menjelaskan manfaat, cara membuat, dan dosis umum.
- Menggunakan bahasa Indonesia.
- Menampilkan contoh pertanyaan cepat.
- Menyalin jawaban.
- Mereset percakapan.
- Menampilkan loading dan pesan error.

Contoh pertanyaan:
- Apa manfaat teh daun kelor?
- Bagaimana cara membuat wedang jahe?
- Herbal apa untuk masuk angin?
- Jelaskan jamu kunyit asam.
- Dosis aman beras kencur?
- Apa manfaat wedang uwuh?

Alur teknis:
1. Pengguna mengetik pertanyaan.
2. Halaman AI mengirim data ke /api/chat.
3. API server membaca GEMINI_API_KEY.
4. API memanggil model Gemini.
5. Jawaban dikembalikan dan ditampilkan.

Environment variable:

GEMINI_API_KEY=API_KEY_GEMINI

Tambahkan variabel tersebut di .env.local untuk lokal dan di Vercel
Environment Variables untuk deployment. Jangan memasukkan API key ke kode,
GitHub, screenshot, atau dokumen publik.

Catatan: Herbal AI adalah alat edukasi dan bukan pengganti dokter atau
apoteker.

11. GAMBAR DAN DEPLOYMENT
-------------------------

Lokasi gambar:

public/images/

Contoh path:
- /images/kunyit.png
- /images/mengkudu.png
- /images/mengkudu-hutan.png
- /images/keji-beling.png
- /images/gandapura.png
- /images/pala.png

Penting:
- Nama file harus sama persis dengan field gambar.
- Vercel menggunakan Linux yang peka huruf besar-kecil.
- "mengkudu.png" berbeda dengan "Mengkudu.png".
- File harus berada di folder public.
- Path harus diawali /images/.

Jika gambar tidak muncul:
1. Cek file di public/images.
2. Cek ekstensi.
3. Cek huruf besar-kecil.
4. Cek field gambar di jamu.json.
5. Pastikan file masuk commit dan deploy ulang.

16. DEPLOY KE VERCEL
--------------------

1. Push project ke GitHub.
2. Buka vercel.com.
3. Pilih Add New Project.
4. Pilih repository project.
5. Pastikan Framework Preset adalah Next.js.
6. Build Command: npm run build.
7. Install Command: npm install.
8. Tambahkan GEMINI_API_KEY pada Environment Variables.
9. Aktifkan environment Production, Preview, dan Development sesuai kebutuhan.
10. Klik Deploy.
11. Uji route /, /katalog, /resep, /ai, dan /tentang.
12. Uji gambar, pencarian, modal, peta, cetak resep, dan AI.

Jangan mengunggah .env.local ke GitHub.
